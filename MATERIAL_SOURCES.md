# Material Sources

The project can install the following free CC0 Poly Haven texture sets in 1K resolution using:

```bash
./tools/download_polyhaven_cc0_1k.sh
```

## Poly Haven assets

- Concrete Wall 004 — wall material
- Concrete Floor — workshop floor
- Green Metal Rust — painted steel cabinets, door and shelving

Maps used by Godot:

- Diffuse / Albedo
- OpenGL Normal
- ARM packed texture: R = Ambient Occlusion, G = Roughness, B = Metallic

Poly Haven publishes these assets under CC0.

The local stainless steel, chalkboard and white-plastic materials remain lightweight project materials and now use their normal maps as well.
